Changelog

What changed, release by release.

The short version of each release. The full list, with every fix, is CHANGELOG.md on GitHub.

v0.16.0Latest

Remembra Relay

One agent stops, the next one already knows. When a session ends, Remembra Relay saves a handoff built from facts it reads from git. When the next session starts, in any tool or on any machine, that agent gets a short brief of where the work stands. Every handoff stays on the trail.

$pipx install --force 'remembra[mcp]>=0.16'$remembra-install --all$remembra-relay connect --apply

remembra-install asks for your key at a hidden prompt, so it never goes on the command line or into your shell history. connect --apply writes the hooks and keeps a backup of each file; run connect alone first to see every change without writing. Setup guide

What is new

  • Handoffs. At session end, remembra-relay close reads the branch, commits, changed and uncommitted files and unpushed commits from git, and for Claude Code the test runs and open items in the local session transcript. The transcript itself never leaves your machine. The server keeps one handoff: done, not done, failing, next step.
  • Grounded summaries. An agent's own summary is optional and is checked against those facts. The brief shows it as unverified, or as contradicted when git disagrees.
  • Briefs. At session start, remembra-relay brief or the session_brief MCP tool gives the next agent who worked last, what is done, what is failing and the suggested next step, in about 1,500 tokens. Everything another agent recorded is wrapped as untrusted data.
  • The trail. Every handoff and checkpoint in order: remembra-relay trail, and the Trail page in the dashboard.
  • One project on every machine. A repository is identified by its git remote, so the same repo on a laptop, a server or in a worktree is one project.
  • Agent-scoped keys. Give each agent its own key and its handoffs show as key-verified; that key cannot write as another agent. Handoffs closed with a shared key show as self-declared.
  • Agents. Claude Code's and Codex's session hooks are verified, Codex with codex-cli 0.155.0-alpha.16.4, a prerelease (run /hooks in Codex once to trust them). The hooks for Cursor, Gemini CLI, Qwen Code and Kimi follow each tool's docs but have not been run against it yet, so connect leaves them out unless you add --include-unverified. Any agent that speaks MCP can use the session_brief and close_session tools.
  • The dashboard. Home shows what changed since your last visit and the command that continues the work; Trail, Agents and Inbox sit beside it.
  • Lossless memory. The exact text a fact came from is kept as a source record, every derived fact points back to it, and a fact that does not match its source is stored flagged as unverified.
  • New plans. Free, Solo, Pro and Team, with smart credits for AI enrichment of new notes. Handoffs, briefs, the inbox, the trail and search never use credits. Billing moves to Paddle, which sells the plans as Merchant of Record.
  • Sign in with GitHub or Google, and email verification for new accounts.

What changes if you already use Remembra

  • Your plan. If you subscribed before this release, you keep your plan and its price on a grandfathered tier. That tier gets a monthly ceiling on AI enrichment, and a lower cap on notes kept takes effect only after we give you notice.
  • Which project a repository uses. A repository the server has not seen joins the project you configured (REMEMBRA_RELAY_PROJECT or REMEMBRA_PROJECT). Only with nothing configured does it get its own project. To move a repository, run remembra-relay resolve --project <id> --bind.
  • Briefs read differently. What other agents recorded now sits inside an untrusted-data block, an agent's next step is labelled a suggestion, low-trust text is withheld, and a handoff from another branch is flagged as possibly stale.
  • Reserved metadata. POST /memories drops the relay-only metadata keys relay and relay_key, and agent-scoped keys stamp their own agent_id.

Earlier releases

Before Remembra Relay, Remembra was a memory layer for one app or agent at a time. A short summary of each earlier release; CHANGELOG.md has the detail.

v0.13.2April 25, 2026

Product surfaces and the dashboard overview

A sharper public product narrative, dashboard operator overview, runtime billing config, safer docs examples, and release hygiene improvements.

v0.13.1March 30, 2026

Cold Archive & Adaptive Thresholds

Queryable storage for decayed memories, adaptive pruning thresholds, archive restore, and new temporal archive APIs.

  • Cold Archive Tier: Decayed memories move to queryable archive storage with restore paths
  • Adaptive Thresholds: Pruning can adjust by session mode, memory density, and result quality
  • Archive APIs: List, inspect, search, restore, and report archive statistics
  • Cleanup Integration: Decay cleanup can use adaptive thresholds when configured

v0.13.0March 27, 2026

Dashboard v2.0 & Team Collaboration

Two-Factor Authentication, Team Collaboration, Admin Dashboard, Activity Logs, Entity Browser, and npm package.

  • Two-Factor Authentication: TOTP-based 2FA with any authenticator app
  • Team Collaboration: Shared memory spaces with Viewer/Member/Admin roles
  • Admin Dashboard: Full user management (delete, deactivate, reset password)
  • Activity Log: Security audit trail with JSON export
  • Entity Browser: Visual exploration of people, places, concepts
  • Timeline Fix: Proper timezone handling with local time display
  • npm Package: npm install remembra with TypeScript support
  • RBAC Enforcement: Viewer role properly restricted from store/delete
  • SSRF Protection: Webhooks block private IP ranges
  • Error Sanitization: No Python exceptions leaked to clients

v0.12.0March 22, 2026

User Profiles & Smart Auto-Forgetting

User Profiles API, 35+ temporal patterns for auto-TTL, strict mode expiry, event-driven expiry, and client-side shadow TTLs.

  • User Profiles API: GET /api/v1/users/{user_id}/profile returns aggregated facts, activity, topics
  • Smart Auto-Forgetting: 35+ temporal patterns auto-set TTL ("meeting tomorrow" → 36h)
  • Strict Mode 410 GONE: Opt-in mode returns 410 for expired memories instead of silent accept
  • Event-Driven Expiry: expires_at parameter for explicit timestamps
  • Client-side shadow TTLs: the SDK caches expiry locally, so it asks the server less often

v0.10.1March 15, 2026

Centralized Credentials & Bridge Lifecycle

Streamlined credential management, slim recall mode, and full bridge lifecycle control.

  • Centralized Credentials: ~/.remembra/credentials with chmod 600
  • Slim Recall Mode: 90% smaller payloads with slim=True
  • remembra-bridge --stop/--status: Full lifecycle control
  • Port-in-use detection and health checks after startup

v0.10.0March 15, 2026

Universal Agent Installer & Setup Diagnostics

One command configures all your AI tools. Setup diagnostics and local bridge for sandboxed agents.

  • remembra-install --all: Auto-detect and configure all agents
  • 6+ Agents Supported: Claude Desktop, Claude Code, Codex, Cursor, Windsurf, Gemini
  • remembra-doctor: Diagnose setup issues with clear failure labels
  • remembra-bridge: Local proxy for sandboxed agents
  • RBAC Enforcement: Permissions on all memory endpoints
  • Error Sanitization: No stack traces leaked
  • Webhook SSRF Protection: URL validation before delivery

v0.9.0March 9, 2026

Temporal Knowledge Graph & 11 MCP Tools

Bi-temporal relationships with point-in-time queries, 6 new MCP tools, entity graph visualization, and contradiction detection.

  • Bi-Temporal Relationships: Track valid_from, valid_to, and superseded_by
  • Point-in-Time Queries: Ask "Where did Alice work in January 2022?"
  • Contradiction Detection: New relationships auto-supersede old ones with history preserved
  • Entity graph view: an interactive graph of entities and their relationships
  • update_memory: Update content without delete+recreate
  • search_entities: Search the entity graph by name, type, or alias
  • list_memories: Browse stored memories without search query
  • share_memory: Cross-agent memory sharing via Spaces
  • timeline: Temporal browsing filtered by entity and date range
  • relationships_at: Query entity relationships at a specific point in time

v0.8.2March 7, 2026

Encryption at rest and the MCP Registry

AES-256-GCM encryption for memory content and metadata in the vector store (set REMEMBRA_ENCRYPTION_KEY), PII detection, and the MCP server listed in the MCP Registry as io.github.remembra-ai/remembra.

v0.7.2March 6, 2026

Performance and troubleshooting

Fixed an N+1 query in the entity graph, added a rebuild-vectors endpoint, and wrote the troubleshooting docs.

v0.7.1March 3, 2026

Security & API Fixes

Critical security fixes and API completeness improvements.

  • Security: CORS Configuration: Removed allow_origins=["*"], now configurable via environment
  • API: PATCH /memories/{id}: Full implementation (was returning 501)
  • API: Batch Operations: /store/batch and /recall/batch now functional
  • Streaming: SSE Endpoint: /ingest/stream for conversation ingestion

v0.7.0March 2, 2026

Enterprise Features & Cloud Revenue

Webhooks, RBAC, billing and a plugin system for production deployments.

  • Webhook System: Event-driven integrations with HMAC-SHA256 signing and automatic retry
  • RBAC: Three roles (admin, editor, viewer) with 12 granular permissions
  • Memory Conflict Detection: Detect contradictions with configurable resolution strategies
  • Audit Logging: Complete audit trail with JSON/CSV export
  • Stripe billing: subscriptions, usage metering and a customer portal (replaced by Paddle in v0.16.0)
  • Plan Limits: Configurable limits per plan with automatic enforcement
  • Spaces (Multi-tenancy): Isolated memory spaces per organization
  • Import from: ChatGPT, Claude, plain text, JSON, JSONL, CSV
  • Export to: JSON, JSONL, CSV formats
  • Plugin System: auto_tagger, recall_logger, slack_notifier built-in

v0.6.0–v0.6.3March 1, 2026

Temporal Memory & Docker

Time-aware memory with TTL, decay algorithms, and production-ready Docker deployment.

  • TTL (Time-to-Live): Memories can now expire automatically with ttl="30d"
  • Memory Decay Algorithm: Ebbinghaus forgetting curve with access boost
  • Historical Queries: as_of parameter for time-travel recall
  • Entity API: Full CRUD endpoints for entities and relationships
  • Docker Support: Production Dockerfile with docker-compose stack

v0.5.0March 1, 2026

Security Layer

API key authentication, rate limiting, and defense against memory injection (MINJA).

  • API Key Authentication: rem_ prefixed keys with bcrypt hashing
  • Rate Limiting: Per-endpoint limits with Redis or in-memory backend
  • Memory Protection: Input sanitization, trust scoring, provenance tracking
  • Audit Logging: Security events with user/IP tracking (content-free)

v0.4.0March 1, 2026

Advanced Retrieval

Hybrid search, CrossEncoder reranking, and graph-aware recall.

  • Hybrid Search: Combines BM25 keyword + vector semantic matching
  • CrossEncoder reranking: a second pass that reorders recall results
  • Graph-Aware Retrieval: Entity relationship traversal for smarter recall
  • Context Optimization: tiktoken integration for accurate token counting

v0.3.0March 1, 2026

Entity Resolution

Automatic entity extraction, alias matching, and relationship storage.

  • Entity Extraction: LLM extracts PERSON, ORG, LOCATION entities
  • Alias Matching: "Mr. Kim" → "David Kim", "NYC" → "New York City"
  • Relationship Storage: WORKS_AT, SPOUSE_OF, KNOWS, etc.

v0.1.0–v0.2.0March 1, 2026

Foundation

Core memory operations, smart extraction, and consolidation.

  • store(): Store memories with automatic fact extraction
  • recall(): Semantic search across memories
  • forget(): delete memories
  • Smart Extraction: LLM transforms messy text into atomic facts
  • Consolidation: ADD/UPDATE/DELETE/NOOP prevents duplicates
