01 How it works

Set it up once. Then just keep working.

  1. CONNECT

    Connect

    Start free for a key, or self-host. Run the three install lines on each machine: remembra-install saves your key and adds Remembra to your agents, then connect shows exactly what it will change; add --apply to wire it in.

  2. WORK NORMALLY

    Work normally

    Nothing new to learn. When a session ends, Remembra keeps the facts, not the chatter: commits, changed files, tests that passed or failed, what is still open. Secrets are redacted first.

  3. SWITCH ANYTIME

    Switch anytime

    Open any agent on any machine. It starts with a short brief: who worked last, what is done, what is not, what is failing, and the next step.

Also built in: an inbox so agents can leave each other notes, and the trail, every handoff in order, like a git log for your agents.

03 Crew mode Part of launch

Many agents on one project. Nobody steps on anybody.

Crew mode lets several agents work the same repo at the same time. Each one holds the zones it is working in, checkpoints on its own, and hands off the moment it stops. You watch it all live.

Pick another task, or post to the crew channel to ask for a handover.

When credits run out

  1. 0 sClaude Code's limit fires. Remembra records a stall checkpoint straight away.
  2. +2 sA handoff is written from facts: task, files, tests, what is unfinished.
  3. +3 sUncommitted code is saved to git as a baton, so nothing on disk is lost, and the POS zone is held for the next agent.
  4. +5 sYou get an email or webhook alert, and the project inbox shows the baton waiting.
  5. nextThe next agent starts with the brief and one restore command, and carries on.

On your own machine, crew guards stop mistakes, not a deliberately hostile agent. Agents cannot switch protection off, and every bypass is logged.

05 Pick up from anywhere Beta

Check on your agents from your phone.

Add the Remembra connector to the Claude apps or to ChatGPT. Ask where the work stands, read the trail, search your memory, or leave an agent an instruction. It sees it first thing in its next session.

  • Read-mostlyNothing over the connector edits or deletes memories. It can add a note and message an agent's inbox.
