01 How it works

Set it up once. Then just keep working.

  1. CONNECT

    Connect

    Start free for a key, or self-host. Run the three install lines on each machine: remembra-install asks for your key at a hidden prompt (it never goes on the command line), shows what it will add to each agent it finds and writes only after you say yes. Then connect shows exactly which hooks it will add; add --apply to wire them in.

  2. WORK NORMALLY

    Work normally

    Nothing new to learn. When a session ends, Remembra keeps the facts, not the chatter: commits, changed files, tests that passed or failed, what is still open. Secrets are redacted first.

  3. SWITCH ANYTIME

    Switch anytime

    Open any agent on any machine. It starts with a short brief: who worked last, what is done, what is not, what is failing, and the next step.

Also built in: an inbox so agents can leave each other notes, and the trail, every handoff in order, like a git log for your agents.

02 Every agent, every machine

Whatever you run, wherever it runs.

Your memory lives in the cloud, not on one laptop. Start at your desk, keep going on a server, finish from home, with whichever agent still has credits.

  • laptop
  • desktop
  • cloud VM
  • server

Claude Code's and Codex's session hooks are verified: Codex with a prerelease of codex-cli 0.155 (codex exec, with a local stand-in for the model); other Codex versions have not been run. Codex runs them only after you trust them, so open Codex and run /hooks once after connecting. The hooks for Cursor, Gemini CLI, Qwen Code and Kimi are unverified: they follow each tool's docs but have not been run against it yet. connect is a dry run until you add --apply, and it leaves the unverified hooks out unless you also add --include-unverified. Until they are tested, those agents read the brief and write their handoff through Remembra's MCP tools, as does any MCP agent. remembra-install sets up those tools for Claude Code, Claude Desktop, Codex, Cursor and Gemini CLI. Windsurf, Qwen Code and Kimi you add by hand for now; the setup guide has the block to paste.

04 Pick up from anywhere Beta

Check on Codex, Cursor or Claude Code from your phone.

Add the Remembra connector to the Claude apps or to ChatGPT. Ask where the work stands, read the trail, search your memory, or leave an agent an instruction. It sees it first thing in its next session.

  • Claudeclaude.ai, Claude Desktop and the Claude phone apps, as a custom connector.
  • ChatGPTOn the web, in developer mode (Plus, Pro, Business, Enterprise and Education).
  • Read-mostlyNothing over the connector edits or deletes memories. It can add a note and message an agent's inbox.
