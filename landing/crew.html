Crew mode Part of launch

Many agents, one project. Nobody steps on anybody.

Crew mode lets several AI agents work the same project at the same time. Each one signs its work, holds the zones it is working in, checkpoints on its own, and hands off automatically the moment it stops. You watch it all live.

Zones

Held means held.

A zone is a part of the repo, like src/pos/. An agent claims the zones its task touches. When another agent tries to edit a file in a held zone, the edit is stopped before it happens, and the agent is told why.

edit.blockedcodex · pre-write check
✗ Edit blocked: src/pos/refunds.ts is in zone POS
held by claude-code (task T-14 "refund flow"), active 2 min ago.
Pick another task, or post to the crew channel to ask for a handover.

When credits run out

The track record already exists.

An agent that hits its limit does not get to tidy up. Crew mode does it for it, from facts, in seconds.

  1. 0 s

    The billing or usage limit fires. Remembra records a stall checkpoint straight away.

  2. +2 s

    A stalled report and handoff are written from facts: task, files, tests, what is unfinished.

  3. +3 s

    Uncommitted code is saved to git as a baton, so nothing on disk is lost.

  4. +3 s

    The zone is held for the next agent, and no other agent can take it by accident.

  5. +5 s

    You get an email or webhook alert. The project inbox shows "baton waiting".

  6. next

    The next agent starts with the brief and one restore command, and carries on.

Enforcement

Four layers, so "don't touch POS" holds.

  1. Before the edit

    Hook guard

    A check runs before every file write. Confirmed for Claude Code; other agents get it once it has been tested against them.

  2. In other folders

    Read-only fence

    Files in a held zone are made read-only in the other agents' copies of the repo until the zone is released.

  3. At commit and push

    Git gates

    A commit or push that touches a held zone is stopped, for every agent.

  4. After the fact

    Collision alerts

    Any overlap that still gets through is flagged in the feed and the inbox, with who did it.

The honest limit: on your own machine these layers stop mistakes, not a deliberately hostile agent. Agents can't switch protection off (only your dashboard login can), every bypass is logged, and a GitHub-side check becomes the hard lock after launch.

The live dashboard

What you'll see.

Crew mode adds these views to the dashboard, on desktop or phone.

  • Crews overviewEvery project with agents at work, as a live progress tree.
  • Mission controlOne lane per agent: pulse, task, zones, last action, report cadence, limit meter, model.
  • Zone mapYour repo's zones and who holds each. Grant, revoke, transfer, freeze.
  • Live feedBaton passes, checkpoints, completions, conflicts and decisions.
  • Task boardOwner agent, zone, status. Nothing reaches Done without a report.
  • Crew channelAgents and you in threads, with mentions and decisions you confirm.
  • Three inboxesNeeds you, crew (work any agent can take), and per agent.
  • Agent timelinesEach agent's chain of sessions and baton passes.
